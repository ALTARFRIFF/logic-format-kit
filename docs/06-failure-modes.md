# 附录 06 —— 失败模式速查

> 按**症状**查。每行都来自实际踩过的坑。

---

## 1. `.patch` / `.cst`

| 症状 | 根因 | 修法 |
|---|---|---|
| 加载 `X.patch`，Logic 里显示成**模板的名字**，内容也是模板的 | 5 个 UUID 里有旧值（最常见是三个条带块末尾的 16 字节） | 换**全部 5 个**，且两两不同（`docs/01 §4`） |
| Patch 名字对，但 UI 显示的是缩写 / 完全不对 | `.cst` 名字块只有 **17 字节字段**（≤10 字符），UI 名字来自**文件夹名 + `Channel_name`** | 两处都改；`.cst` 里放缩写 |
| 插件**顺序和模板一模一样** | 只改了 `+12`（u64 大端），没改 `+42`（u32 小端） | 两个都写（`docs/01 §3`） |
| 插件少了一个 / 多了空的 | 拼块时漏了尾块，或槽位重复 | 解析后断言：插件数、槽位互不相同、块流走到底 |
| Logic 直接拒绝解析 `.cst` | 块长度字段错了（通常是 base64 替换时改了长度） | 用"非空白字符槽位填充"写回（`docs/01 §7`），断言字符数相同 |
| 名字超长后整个 patch 坏 | 名字字段只有 17 字节 | 截到 10 字节以内 |
| Channel Strip Setting 丢了 Send | CSS **不携带 Send** | 存成 `.patch` |
| 想存 Bus / Output 通道条，存不出来 | Logic 设计上不支持（`docs/04 §7`） | 用 Aux；Output 交给工程模板 |

## 2. 插件参数

| 症状 | 根因 | 修法 |
|---|---|---|
| 值写进去了，Logic 里**没变** | 写错容器 / 写错参数下标 | 先 `docs/02 §1` 认 magic；用 `param-maps` 确认下标 |
| Pmtr 插件改完，Logic 显示别的参数变了 | 用 `tag` 当偏移用了 | **按偏移寻址**，`tag` 只是标签 |
| Pmtr 记录数与参数数不匹配就报错 | 只读参数（电平表）没有记录 | 记录数 ≤ 参数数是正常的；用 `float[1]==float[2]==float[3]` 对齐校验 |
| 值差 0.1 dB 左右 | 拿 MCU 的 LCD 当标定标准（会四舍五入） | 用 `au_dump --string` 问插件自己 |
| Pro-Q 4 频率写成 Hz，结果离谱 | 频率列存 `log2(Hz)` | 换算：`log2(1000) = 9.96578` |
| Pro-Q 4 某段不生效 | 只写了参数没写 `Used = 1`（关闭的段也必须显式写 0/1） | 每段都写 `Used` |
| Pro-DS / Pro-MB 改了没反应 | 它们是 **flags 稀疏容器**，不是 FFBS | 见 `docs/02 §4` |
| iZotope 参数改了没反应 | +0/+8/+12 三个长度字段没重算，或 +0 被覆盖 | 原样保留 +0，重算 +8/+12（`docs/02 §6`）；未回读验证过 |
| JUCE 插件报"找不到参数"，`have:` 是空 | **XML 已经坏了**（常见于 pad 点插在 `>` 前） | 改完必须 `parse` 一次并断言根元素在 |
| FM 参数按 `id` 找不到 | `<param id="1" name="Output">` 里 `id` 只是序号 | 按 `name` 寻址 |

## 3. `.logicx`

| 症状 | 根因 | 修法 |
|---|---|---|
| Logic 打不开工程 | 文件长度字段（全文件 `+16`、Song `+30`）没同步 | 任何变长写入都要修这两处 |
| 打开了，但轨道/对象少了一堆 | 某个父级长度字段错了 | 优先做等长写入；不要真插入 |
| 拍号设对了，但**显示在错误的小节** | 只改了 `+13`（小节缓存），没改 `+5`（真实位置） | 两个都写：`pos = ceil((tick+38400)/256)` |
| 拍号只改了"一个"小节，后面全变了 | **这是 Logic 的正常行为**，不是 bug | 拍号从设定小节起向后持续 |
| 调号写对了但和弦被移调了 | 写入顺序错 | **先写调号，再写和弦** |
| 调号显示成 `A#` 而不是 `Bb` | `Disable ♭♯` 标志（`0x80000000`） | 需要降号显示就置这个位 |
| 和弦"删除"了但还在 | Logic 保留记录，且会用"继承上一个和弦"填充空白 | 用 `No Chord` 事件（mask = 0） |
| 和弦内容对，但名字怪异 | 位图是**相对根音**的；也可能是显示缓存 `+478` 与位图不一致 | 同时写 `+468/+470/+478`；`+479/+480` 不要碰 |
| 加 `13` 被改成 `6` | Logic 的互斥规则：`13` 必须带 7 度 | 见 `docs/03 §7` |
| 第二个事件位置全错 | 拍号变化后没分段换算 tick | 先按拍号分段累加，再算位置 |
| 改完一个值，文件涨了 10+ KB | 正常：Logic 懒创建对象 | 不要当成错误 |
| 两次保存 UUID 全变了 | 正常：Logic 每次保存都重生成 | diff 前先掩 UUID |

## 4. 工具 / 脚本

| 症状 | 根因 | 修法 |
|---|---|---|
| `TypeError: 'generator' object is not subscriptable` | `cst_chunks()` 是生成器 | 先 `list(...)` |
| `subprocess.run(capture_output=True, timeout=…))` **卡死** | 离进程 AU 留下孙进程握着管道，`communicate()` 永远等不到 EOF | 用 `Popen(stdout=<临时文件>, start_new_session=True)` + `os.killpg` |
| `UnicodeDecodeError` 处理插件名 | 插件名不是 UTF-8 | 读 bytes 再 `.decode("utf-8", "replace")` |
| 按 subtype 过滤，却拿到第一个 blob | 参数被写成"覆盖"而不是"过滤" | `subtype = args.subtype if args.subtype else ident["subtype"]` |
| 批量写多个 blob，第二个读到垃圾（`not a VC2! blob`） | 按**升序**写，第一次变长后后面所有偏移失效 | **按偏移降序**写 |
| 改 plist 里的 state，报 `state length would change` | 干净的做法是"槽位填充"，不要整段替换 | 见 `docs/01 §7` |
| `au_dump` 对某插件返回 `-3000` | iLok 保护的插件不能进程内实例化 | 用 `AudioComponentInstantiate(..., LoadOutOfProcess, ...)` |
| AU 的 FourCC 猜错 | 猜的 | 读 `Contents/Info.plist` 的 `AudioComponents` |

## 5. 方法论级别的坑（最贵）

| 坑 | 症状 | 正解 |
|---|---|---|
| **不掩 UUID 就 diff** | 改一个值产生 16 000+ 处"差异"，看着像整个文件都变了 | 先掩 UUID，再 diff（`CORE.md §2`） |
| **跨文件 diff 找字段** | 两个文件之间有大量无关差异（保存时间戳、懒创建对象） | 用**同一文件内的多条记录**互相对比（阶梯法） |
| **不等长两文件逐字节比** | 插入点之后全部错位，产生 16 216 处假差异 | 先定位插入点，或只用等长对 |
| **用 8 字节粒度 SequenceMatcher 比 131 KB** | 单次超 60 秒 | 改等长数组扫描 |
| **猜"某字段应该是记录数"** | 拍号/调号的长度字段试了两轮都落空 | 用已知内容对齐多个文件，**读值反推编码** |
| **拿 UI 数字当存储值** | 差 0.1 dB / 差一小节 | 只信字节 + 回读 |
| **从零构造容器** | 静默失败、无法迭代 | 模板 + 改写 |

---

## 6. 一句诊断口诀

> **文件变了吗？ → 只变了该变的地方吗？ → 读回来对吗？ → Logic 认吗？**
> 四步里任何一步答不上来，就不要宣称成功。
